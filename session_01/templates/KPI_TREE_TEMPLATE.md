# Plantilla - Árbol de KPIs

## Objetivo de negocio
Ejemplo: mejorar cumplimiento operativo y reducir riesgo de costos.

| | | | | |

## KPIs diagnóstico
| KPI diagnóstico | Qué explica | Dimensión recomendada | Acción posible |
|---|---|---|---|
| | | | |

## Árbol lógico
Objetivo -> KPI principal -> Desviación -> Dimensión -> Causa probable -> Acción.

## Preguntas de validación
- ¿El KPI principal puede mejorar aunque un KPI diagnóstico empeore?
- ¿El KPI tiene meta o umbral?
- ¿La dimensión ayuda a decidir o solo describe?
- ¿La acción está dentro del control de la audiencia?

## KPIs mineros sugeridos
- Producción: cumplimiento de producción %, toneladas por hora productiva, brecha plan vs real.
- Mantenimiento: downtime, MTTR aproximado, backlog, órdenes críticas abiertas.
- SLA: cumplimiento SLA %, breach hours, tiempo promedio de resolución.
- Energía: kWh total, costo energía, kWh por output.
- HSE: incidentes por severidad, acciones abiertas, acciones vencidas.
