# Recap Power BI Desktop - Pasos Manuales

## Objetivo
Reconocer las zonas de Power BI Desktop y entender qué responsabilidad cumple cada una en una solución BI.

## Pasos
1. Abrir Power BI Desktop.
2. Crear archivo en blanco.
3. Identificar la cinta superior: inicio, transformar datos, modelado y visualizaciones.
4. Abrir **Power Query** desde Transformar datos.
5. Cerrar Power Query sin aplicar cambios si solo se está demostrando.
6. Ir a **Vista de modelo** para observar relaciones.
7. Ir a **Vista de informe** para crear visuales.
8. Explicar dónde se escriben medidas DAX.

## Preguntas de reflexión
- ¿Qué ocurre si una limpieza se hace como columna calculada en vez de Power Query?
- ¿Qué riesgo existe si el modelo no tiene relaciones claras?
- ¿Por qué una medida DAX debe ser reusable?
