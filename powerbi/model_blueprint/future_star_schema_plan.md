# Plan Futuro de Modelo Estrella

## Módulo 3
Este archivo será la base para construir un modelo estrella formal.

## Principios
- Hechos al centro.
- Dimensiones compartidas.
- Llaves limpias y consistentes.
- Granularidad documentada.
- Relaciones simples y explicables.

## Riesgos a revisar
- Fechas múltiples en una misma tabla de hechos.
- Dimensiones con relaciones entre sí, como equipo-área.
- Hechos que podrían analizarse juntos pero tienen granularidades distintas.
- Relaciones muchos-a-muchos no justificadas.

## Resultado esperado futuro
Modelo con medidas reutilizables y navegación semántica clara para tableros ejecutivos, operativos y de proyecto.
