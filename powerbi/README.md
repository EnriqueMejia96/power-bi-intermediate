# Guía Manual Power BI - Módulo 1

Esta carpeta guía el trabajo manual en Power BI Desktop. El repositorio no crea `.pbix`, no abre Desktop automáticamente y no publica en Power BI Service.

## Flujo recomendado para el laboratorio
1. Generar y validar datos desde Python.
2. Abrir Power BI Desktop manualmente.
3. Importar CSV desde `data/training/sample`.
4. Revisar Power Query.
5. Crear relaciones básicas en Vista de modelo.
6. Crear visuales simples en Vista de informe.
7. Documentar hallazgos en el Diseño de solución BI.

## Carpetas
- `manual_steps`: instrucciones operativas.
- `model_blueprint`: borrador de modelo y plan de modelo estrella.
- `dax_backlog`: medidas futuras para Módulo 4.
- `report_bocetos`: bocetos textuales para páginas potenciales.

## Límite del Módulo 1
Solo se busca comprensión arquitectónica. El diseño final se construirá gradualmente en módulos posteriores.
