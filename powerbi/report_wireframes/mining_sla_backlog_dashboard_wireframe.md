# Wireframe - SLA y backlog minero

## Audiencia
Gestión de servicios, mantenimiento, operaciones y PMO.

## Preguntas de negocio
- ¿Qué servicios incumplen SLA?
- ¿Dónde se acumulan órdenes críticas abiertas?

## KPIs
% cumplimiento SLA, breach hours, tiempo promedio de resolución, backlog, órdenes vencidas y retrabajo.

## Visuales recomendados
Tarjetas SLA, barras por servicio, matriz prioridad-área, tendencia de backlog y tabla de órdenes críticas.

## Filtros
Servicio, prioridad, estado, área, source system y periodo.

## Drill-through
Servicio -> órdenes; área -> SLA, backlog y responsable.

## Tooltips sugeridos
Target hours, actual hours, breach hours, prioridad y sistema fuente.

## Uso posible de IA
Convertir brechas SLA en recomendaciones de priorización.

## Riesgos de interpretación
Un SLA cumplido no siempre implica bajo riesgo si existen acciones HSE abiertas o backlog crítico.
