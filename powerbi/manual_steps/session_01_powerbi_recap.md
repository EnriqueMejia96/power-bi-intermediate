# Recap Power BI Desktop - Sesión 01

## Propósito
Guiar al estudiante por las áreas principales de Power BI Desktop desde una mirada arquitectónica.

## Mapa de componentes
| Componente | Para qué sirve | Error común |
|---|---|---|
| Obtener datos | Conectar archivos/fuentes | Importar todo sin propósito |
| Power Query | Preparar y limpiar | Hacer cálculos de KPI aquí sin criterio |
| Vista de datos | Inspeccionar tablas cargadas | Usarla como hoja de cálculo |
| Vista de modelo | Definir relaciones | Confiar ciegamente en autodetección |
| DAX/Modelado | Crear medidas | Escribir DAX antes de entender negocio |
| Vista de informe | Comunicar decisiones | Crear visuales decorativos |

## Secuencia didáctica
1. Mostrar importación de CSV.
2. Entrar a Power Query y revisar columnas.
3. Aplicar cambios.
4. Mostrar Vista de modelo y relaciones.
5. Crear visuales simples.
6. Volver al plano de solución y preguntar qué decisión habilita.

## Frase clave
"Power BI no empieza en el gráfico. Empieza en una pregunta de negocio y termina en una decisión."
