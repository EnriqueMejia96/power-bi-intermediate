# Ejemplos de dashboards mineros

## Propósito
Dar ideas de páginas Power BI para el caso minero sin crear un archivo `.pbix`.

## Cómo se aplica a la especialización
Los estudiantes diseñan wireframes en Módulo 1 y luego los convierten en reportes cuando existan modelo y DAX.

## Conexión con Power BI
Cada página debe tener audiencia, decisión, KPIs, visuales, filtros, drill-through, tooltips y validaciones.

## Conexión con el dataset
Los ejemplos usan datos de productividad, mantenimiento, SLA, costos, energía, incidentes y proyectos.

## Conexión con módulos 1-6
Sirve como puente entre blueprint inicial, modelamiento, medidas y narrativa visual.

## Páginas sugeridas
- Resumen ejecutivo minero.
- Operaciones mina y planta.
- Mantenimiento y confiabilidad.
- SLA y backlog.
- Energía y eficiencia.
- Seguridad HSE.
- Análisis de causa raíz.

## Preguntas de negocio
- ¿Qué cambió respecto al plan?
- ¿Qué área necesita acción inmediata?
- ¿Qué combinación de fallas, SLA, energía y HSE explica el riesgo?

## KPIs ejemplo
Producción real vs plan, downtime, backlog, SLA %, costo real vs presupuesto, kWh/output, incidentes críticos y acciones vencidas.

## Riesgos de interpretación
Evitar páginas con demasiados indicadores. Cada visual debe responder una pregunta.

## Apoyo de IA
IA puede proponer layout y narrativa ejecutiva, pero no debe inventar datos ni reemplazar validación.

## Validación profesional
Revisar consistencia visual, definiciones, contexto de filtro, segmentadores y trazabilidad del dato.
